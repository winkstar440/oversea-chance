# oversea-chance

# 啟程 Embark

為手持特區護照 / BNO 的香港人而設的海外機會探索平台。把分散在各國政府網站、論壇與社群裡的出路，整合到一個零依賴、手機可用的互動頁面。

## 功能
- 🗓 **今日要處理** —— 按護照與生日自動提示簽證到期、申請季、行前清單
- 🧭 **一分鐘配對** —— 回答幾個問題，個人化推薦目的地與路徑
- 🌏 **工作假期中心** —— 13 個夥伴經濟體 + 通用租房住宿平台
- 🤝 **更多機會** —— 義工換宿、數位遊牧簽證、海外實習、文化交流（JET / TAPIF / AFS）
- 🌸 **女性專區** —— 獨立 section 集中女性專屬獎學金、旅行團、住宿與職涯網絡
- 📋 **我的規劃台** —— 雲端同步的願望清單、日程與筆記
